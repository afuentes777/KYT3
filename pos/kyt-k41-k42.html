Propuesta de valor

Funcionalidad dual con
base de diseño moderno

El K&T-K41 / K42 combina una pantalla principal de 15,6" HD para el cajero con una segunda pantalla de 10,1" HD para el cliente, todo montado sobre una base pedestal con rotación de 360° que permite ajustar la orientación sin mover el equipo. Su diseño limpio y su base redonda lo diferencian visualmente de los POS convencionales, proyectando una imagen corporativa de primera línea.

  • Pantalla cajero 15,6" HD — táctil capacitivo 10 puntos
  • Pantalla cliente 10,1" HD — orientable hacia el comprador
  • Base pedestal con rotación 360° — ajuste sin mover el equipo
  • Compatible con Windows y Android según configuración
  • Puertos USB, COM, LAN y RJ11 para periféricos POS
  • Integración nativa con KONEX® y DAVINCI® de K&T
Pantallas del K41 / K42

Doble pantalla para la experiencia
cajero-cliente más completa

Cada pantalla tiene un propósito definido que mejora la eficiencia del cobro y la confianza del cliente.

15,6"
Pantalla cajero — HD 1366×768 · Táctil capacitivo
Pantalla principal del operador con táctil multitouch capacitivo de alta precisión. Resolución HD para interfaces POS con múltiples categorías, botones y funciones del sistema.
10,1"
Pantalla cliente — HD · Visor de transacción y publicidad
Display secundario orientado al cliente para mostrar el detalle del pedido, totales, descuentos y mensajes de marketing en el momento del cobro. Reduce disputas y aumenta la confianza del comprador.
