Propuesta de valor

El POS que se adapta
a cualquier escenario

El K&T-K21 / K22 es un terminal POS inteligente de escritorio que redefine la flexibilidad operativa. Su pantalla ajustable permite alternar entre modo cajero asistido y modo autoservicio sin necesidad de equipos adicionales. La base magnética estable y el soporte VESA universal lo hacen igualmente apto para mostrador, montaje en pared o brazo articulado, cubriendo todas las configuraciones de atención modernas.

  • Modo cajero + autoservicio intercambiables sin hardware adicional
  • Pantalla principal ajustable en ángulo e inclinación
  • Base magnética estable — diseño compacto y ligero
  • Soporte VESA universal — mostrador, pared o brazo
  • Pantalla cliente con visualización de transacción en tiempo real
  • Compatible con Windows y Android según configuración
Modos de operación

Dos modos en un mismo equipo:
cajero y autoservicio

El K21/K22 permite cambiar el modo de operación mediante configuración de software, sin necesidad de adquirir equipos diferentes para cada escenario.

Cajero
Modo asistido — pantalla orientada al operador
El operador gestiona la transacción desde la pantalla principal mientras el cliente visualiza el resumen en la segunda pantalla. Modo estándar para caja rápida, atención en mostrador y puntos de servicio con personal.
Autoservicio
Modo self-service — pantalla orientada al cliente
La pantalla gira hacia el cliente para que realice su pedido o consulta de forma autónoma. Ideal para momentos de bajo personal, quioscos de información, consultas de inventario y check-in exprés.
Flexibilidad operativa

Compatible con múltiples
plataformas operativas

El K21/K22 soporta Windows y Android para integrarse con el software POS de cualquier negocio.

Windows

Plataforma empresarial para software POS de gestión, ERP y facturación electrónica. Compatible con la mayoría de soluciones POS del mercado latinoamericano.

Android

Para aplicaciones POS nativas, restaurantes y negocios que usan apps móviles de punto de venta. Arranque rápido y bajo costo operativo.

Linux

Disponible para proyectos con requerimientos de seguridad avanzada, código abierto o integración con sistemas propietarios. Consulte disponibilidad.

Ventajas del K21 / K22

Un POS que evoluciona
con su operación

Doble modo de operación

Cambie entre modo cajero y autoservicio mediante software. Un solo equipo cubre dos escenarios sin inversión adicional en hardware.

Base magnética estable

La base magnética mantiene el equipo firmemente posicionado en el mostrador mientras permite repositionarlo con facilidad cuando es necesario.

Soporte VESA universal

El puerto VESA permite montar el K21/K22 en pared, brazo articulado o pedestal personalizado, eliminando el límite del mostrador convencional.

Diseño compacto

El cuerpo pequeño y ligero ocupa mínimo espacio y se integra estéticamente en cualquier entorno de atención, desde retail hasta hoteles.

Periféricos fáciles de conectar

Cajón de efectivo, impresoras, lectores y datáfonos se conectan directamente mediante USB, COM y RJ11 sin adaptadores adicionales.

Ecosistema K&T integrado

El K21/K22 se integra con KONEX® para gestión de turnos y con DAVINCI® para cartelería digital, creando una experiencia omnicanal completa.
